#  Automated Fact Checker for vernacular news

##  Description  
This project is a Java-based automated fact-checking system that verifies news statements using a dataset and AI integration. It helps detect misinformation by comparing input news with trusted facts.

---

##  Features  
1. Fact checking using dataset  
2. AI-based verification  
3. Confidence score  
4. Explainable output  
5. Fallback mechanism  

---

##  Tech Stack  
- Java  
- File Handling  
- API  

---

##  How to Run  
Open project → Run Main.java → Enter news → Get result  

---

##  Flow  
Input → DataLoader → FactService → Result  

---

##  Note  
AI is integrated in FactService.java with fallback dataset logic.
